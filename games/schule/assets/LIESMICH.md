# Eigene Grafiken

Legt man hier eine PNG mit passendem Namen ab, ersetzt sie die eingebaute
Zeichnung. Fehlt eine Datei, bleibt es bei der gezeichneten — das Spiel läuft
also auch mit leerem Ordner.

## Wände

Werden auf 64 × 64 gebracht, egal wie groß das Original ist. Ohne Transparenz.

| Datei | wofür |
|---|---|
| `wand.png` | Flur- und Raumwand |
| `spind.png` | Spindreihe |
| `tuer.png` | Klassenraumtür |
| `tafel.png` | Tafel |
| `ausgang.png` | Ausgangstür |

## Figuren und Gegenstände

Seitenverhältnis bleibt erhalten (auf 80 px Höhe normiert). Transparenz wird
übernommen — alles unter 50 % Deckkraft gilt als durchsichtig.

| Datei | wofür |
|---|---|
| `kreide.png` | die Lehrkraft, die dich jagt |
| `direktor.png` | versetzt dich, wenn du im Flur rennst |
| `heft.png` | die sieben Hefte |
| `energie.png` | Energiedrink |
| `seife.png` | Seifenstück |
| `zonk.png` | Zonk-Riegel |

Nur eigenes Material hier ablegen. Grafiken aus fremden Spielen gehören nicht
in ein öffentliches Repository.
